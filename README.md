# 建设公告编辑系统

面向建设工程采购/招标公告的**编制—评审—发布—更正—重建**全流程系统。

- **Vue 界面**：录入项目、采购范围、资格、关键日期与附件；冲突预览、版本管理、并行评审、发布与公开页。
- **API 服务**：两种校验模式（draft 仅提示 / strict 阻断）、角色权限、版本不可变、并行评审绑定具体版本、发布一致性校验。
- **SQL 持久层**：sql.js（WASM SQLite），写操作串行事务、提交落盘，维护公告、版本、评审、审批/撤回流转、上传会话与发布记录。
- **对象服务**：独立进程（端口 3010），内容寻址、**不可变**保存固定附件、渲染结果、快照与发布清单；分片上传会话可断点续传。
- **日期规则引擎**：日期依赖来自“用户配置的公告规则”，严格区分**截止日 date（YYYY-MM-DD）**与**带时区时刻 instant（RFC3339）**。
- 系统为编制与流转工具，**不构成、也不替代法律审查**（界面与发布清单均有显著声明）。

## 快速开始

```bash
npm install
npm run seed          # 初始化演示账号与一份激活的公告规则
npm start             # 同时启动 API(3000) 与对象服务(3010)
# 打开 http://localhost:3000
```

## 关键业务规则

### 日期
- 规则 `rule_sets.config` 定义槽位：`date`（截止日，无时分秒/时区）或 `instant`（带时区时刻）。
- `pairs` 定义顺序约束（如“开标时刻不早于投标截止日”），跨 date/instant 时按规则时区归一到日历日比较；同日两个 instant 再比较具体时刻。倒置在**预览**中以 `DATE_INVERSION / INSTANT_INVERSION / TYPE_MISMIX` 等代码指出。
- 相对槽位（`mode=relative`）以计划发布日为锚点推导（如答疑截止 = 锚点 − 7 天）。

### 版本、评审与“需复核”
- 每次“保存版本”生成不可变快照（正文、范围、资格、日期、**附件引用及哈希**）与内容指纹。
- 评审意见（comment/approve/reject）全部**绑定具体版本**；多人可并行评论。
- **改采购范围或替换附件都会改变指纹**：版本不可变，旧批准不能发布新内容——必须保存新版本并重新评审。发布器还会检查版本引用的附件是否已被 `replaced_by` 同名替换，若被替换直接 409。

### 发布一致性（不能发布半套附件）
发布动作一次性校验：
1. 正文非空且足够完整；标题/项目名存在；
2. 规则版一致——批准所依据规则必须仍是当前激活版本；
3. 严格日期/跨字段校验无 error；
4. 附件摘要——每个必需槽位齐备、无 `open` 上传会话、固定对象存在且 **SHA256/大小**与清单一致；
5. 批准指纹与版本指纹一致。

### 发布后修改：原地编辑 vs 追加更正公告
| | 原地编辑后再版 | 追加更正公告 |
|---|---|---|
| 身份/链接 | 同一 id 与公开链接，内容被新版本替换 | 新建更正公告，`supersedes_id` 指向原公告，同属一条 `chain_id` |
| 审批 | 新版本重新评审 | 独立草稿、独立评审 |
| 旧链接 | — | 持续可访问，显著标示“已被更正公告取代/已撤回” |
| 缓存 | 发布即令该链缓存失效（ETag/`chain_epoch`） | 链上所有成员缓存同时失效 |

公开页内存缓存以 `chain_epoch` 校验，发布/撤回/替代均 bump epoch；条件请求带 ETag 返回 304，状态变化后旧 ETag 立即失效。

### 上传与重启
- 上传 = 创建会话 → 分片 PUT（`x-offset` 必须连续，否则 409）→ finalize（校验声明大小与 SHA256，固化为 `att/<sha256>` 不可变对象）。
- 服务重启后：SQL 数据恢复、`.part` 临时文件仍在，未完成会话可继续上传/定稿或中止。

### 正式文件重建
管理员可用发布清单（`manifests/...json`，含快照键、渲染键、附件摘要与槽位、规则版、清单自哈希）**脱离可变数据库正文**重新渲染，逐字节比对渲染哈希、清单签名与全部附件固定对象哈希。

## 目录结构

```
server/
  index.js           HTTP 入口 + 静态托管 + 自举对象服务
  api.js             API：权限/版本/评审/发布/替代链/公开缓存/重建
  db.js              sql.js 持久层、表结构、串行写事务
  dates.js           date/instant 模型、规则推导、跨字段冲突预览
  render.js          确定性 HTML 渲染、发布清单与规范化签名
  object-service.js  不可变对象服务 + 上传会话
  object-client.js   对象服务客户端
  seed.js            演示账号与种子规则
web/                 Vue 3 SPA（本地 vendor，无 CDN 依赖）
test/acceptance.test.js  39 项端到端验收断言
docs/ARCHITECTURE.md
```

## 验收场景对照（见 `npm test`）

- 日期倒置、date/instant 类型混淆、跨字段冲突在预览中被指出；
- 同名附件替换触发关联批准复核；
- 审批与撤回并发竞争：串行事务下先到者成功，后到者收到 409 且明确双方状态；
- 上传未完成不能提交/发布（半套附件拦截）；分片偏移错误 409；
- 服务重启后数据恢复、未完成上传可续传定稿、公开缓存冷重建；
- 规则版本升级后旧批准版本被禁止发布；
- 原地再版与更正公告替代链；旧链接清楚显示有效状态；缓存随链失效；
- 按发布清单重建正式文件，渲染/清单/附件哈希全部一致。
